# Sentiment Analysis of Israel-Palestine Tweets
Sentiment analysis project using Twitter/X data and NLP techniques.

This project analyzes public sentiment related to Israel-Palestine discussions on platform X/Twitter. The analysis includes text preprocessing, sentiment classification, visualization, and insight extraction from tweet data.

## Tools
- Python
- Pandas
- Scikit-learn
- NLP preprocessing
- Data visualization

## Dataset
The dataset contains cleaned tweet data without buzzer accounts.

## Project Structure
- `notebooks/` contains the analysis notebook.
- `data/` contains the dataset.
- `requirements.txt` contains required Python libraries.

## Output
The project provides sentiment distribution, text patterns, and insights from public opinion.
